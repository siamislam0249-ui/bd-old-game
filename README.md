# 🇧🇩 এক্কাদোক্কা (কুতকুত) 3D - Node.js & Three.js Web Game
### Traditional Bangladeshi Folk Game "Ekkadokka" in Modern 3D

একটি আধুনিক, দৃষ্টিনন্দন এবং পূর্ণাঙ্গ ৩ডি ওয়েব গেম—যা রেফারেন্স ছবির আদলে খাঁটি গ্রামীণ মাটির উঠোন, খড়িমাটির দাগ এবং ঐতিহ্যবাহী নিয়মের সমন্বয়ে **Node.js, Express এবং Three.js** দিয়ে তৈরি।

---

## 🌟 ৩ডি গেমের প্রধান আকর্ষণসমূহ

1. **আধুনিক ৩ডি গ্রাফিক্স ও ফিজিক্স (Three.js):**
   - রিয়েল-টাইম শ্যাডো, আলো ও টেক্সচার্ড গ্রামীণ মাটির উঠোন।
   - ৩ডি পোড়ামাটির চাড়া বাতাসে উড়ে, পল্টি খায় এবং মাটিতে স্লাইড করে।
   - এক পায়ে লাফানো ৩ডি বাঙালি ছেলে কার্টুন মডেল।
2. **রেফারেন্স ছবির কোর্ট জ্যামিতি:**
   - উপরে বড় বর্গক্ষেত্র যা কর্ণ দিয়ে ৪টি ত্রিভুজাকার ঘরে বিভক্ত (১, ২, ৩, ৪)।
   - নিচে দুটি অনুভূমিক আয়তক্ষেত্রাকার ঘর (৫ এবং ৬)।
   - কোর্টের নিচে খোলামেলা বেসলাইন ও দাঁড়ানোর জায়গা।
3. **আধুনিক গ্লাস মরফিজম মোবাইল UI:**
   - ফ্রস্টেড গ্লাস HUD, কমপ্যাক্ট স্কোরবোর্ড ও স্ট্যাটাস বাবল।
   - 🎥 ক্যামেরা ভিউ পরিবর্তন (আইসোমেট্রিক ৩ডি অথবা টপ-ডাউন ভিউ)।
   - স্ক্রিনে আঙুল দিয়ে সোজা সামনের দিকে টেনে নিশানা করার জন্য ৩ডি প্যারাবোলিক গাইড ও ডায়নামিক কালার কোডেড লক্ষ্য গোলক।
4. **Render.com ও ক্লাউড রেডি:**
   - Node.js ও Express ব্যাকএন্ড সার্ভার (`server.js`)।
   - `/health` এন্ডপয়েন্ট ও অটোমেটিক পোর্ট বাইন্ডিং।

---

## 🚀 Render.com-এ ফ্রিতে হোস্ট করার নিয়ম

1. আপনার গিটহাব অ্যাকাউন্টের এই রিপোজিটরিতে কোড পুশ করা থাকবে:
   👉 `https://github.com/siamislam0249-ui/bd-old-game.git`
2. [**render.com**](https://render.com)-এ গিয়ে আপনার GitHub দিয়ে লগইন করুন।
3. **New +** বাটনে ক্লিক করে **Web Service** সিলেক্ট করুন।
4. আপনার রিপোজিটরি **`bd-old-game`** সিলেক্ট করুন।
5. নিচের সেটিংসগুলো দিন:
   - **Name:** `ekkadokka-3d` (বা আপনার পছন্দের নাম)
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** `Free`
6. নিচে **Deploy Web Service** বাটনে ক্লিক করুন! ২ মিনিটের মধ্যে আপনার ৩ডি গেম বিশ্বব্যাপী লাইভ হয়ে যাবে!

---

## 💻 লোকাল মেশিনে চালানোর নিয়ম

```bash
# ডিপেন্ডেন্সি ইন্সটল
npm install

# সার্ভার চালু করুন
npm start
```

এরপর যেকোনো ব্রাউজারে যান:
👉 `http://localhost:3000`
